# Prompts Used — Project 4: Organize the Mess

## Prompt 1 (initial)
Write a Python script that scans a folder, finds duplicate files (by content, not just filename),
flags large files, and groups files by type — but show me a full plan of every action first and
wait for my approval before changing anything.

## Prompt 2 (safety refinement)
Make sure the execute step only ever copies files into a new output folder, never deletes or
overwrites anything in the original folder, and require me to literally type YES to confirm
before any file operation happens.

## Prompt 3 (verification)
Explain in plain English how the duplicate detection actually decides two files are identical —
is it just comparing filenames, or the actual file content?
