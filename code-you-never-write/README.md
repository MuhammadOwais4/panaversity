# Code You Never Write — Lecture 7 Assignment

**Student:** Muhammad Owais
**Course:** Panaversity Agent Factory — Code You Never Write (Crash Course)
**AI Tools Used:** Claude (Anthropic), ChatGPT

## Summary

This repository contains four real-world projects built using the "Code You Never Write" approach —
describing real problems to an AI tool, generating working scripts without writing the code by hand,
and verifying every result against a known fact before trusting it.

| Project | Problem Solved |
|---|---|
| [Project 1 — Money Detective](./project-1-money-detective) | Finds recurring charges, forgotten subscriptions, and duplicate payments in transaction history |
| [Project 2 — What's My Grade, Really](./project-2-whats-my-grade) | Calculates true current grade using teacher's exact grading rules (weights, dropped scores) |
| [Project 3 — The Books Don't Match](./project-3-books-dont-match) | Reconciles a hand-counted total against a messy digital payment record |
| [Project 4 — Organize the Mess](./project-4-organize-the-mess) | Safely finds duplicate/large files in a messy folder with a dry-run-first workflow |

Each folder contains: the final script, a short README, the prompts used, and sample data/output.

> Note: Real personal data (bank account numbers, real names, real grades) has been replaced with
> sample/dummy data for privacy, per assignment instructions. The scripts work identically on real data.
